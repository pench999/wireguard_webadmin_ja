デフォルトポート

標準の docker-compose.yml では、TCP ポート範囲 8080-8089 が指定されています。別の範囲へポート転送を変更する場合は、docker-compose.yml を手動で編集し、デプロイ手順に記載された Docker Compose の手順を再実行してください。

宛先タイプ: ピア

ポートリダイレクトは、優先度 0 が割り当てられた最初のピア IP アドレスを優先します。

宛先タイプ: IP アドレス

ポート転送ルールは、指定した IP アドレスへ転送します。その IP アドレスまたはネットワークをピアへ割り当てておく必要があります。

転送ルールの追加

より厳格なファイアウォール設定に対応するため、転送を許可するルールを自動生成します。

送信元のマスカレード

ピアが VPN をデフォルトゲートウェイとして使用しない場合の一時的な対処です。ただし、すべての接続の送信元アドレスが WireGuard インスタンスの IP アドレスに書き換わるため、この設定は推奨されません。
